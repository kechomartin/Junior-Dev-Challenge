SimpleDB - Custom RDBMS

In-memory relational database with SQL interface

Task Manager Demo

This app uses the SimpleDB backend to manage tasks with full CRUD operations.

Features

  • ✅ CREATE TABLE with column types (INTEGER, TEXT, REAL, BOOLEAN)
  • ✅ PRIMARY KEY and UNIQUE constraints
  • ✅ NOT NULL constraints
  • ✅ Automatic indexing on PRIMARY KEY and UNIQUE columns
  • ✅ INSERT, SELECT, UPDATE, DELETE operations
  • ✅ WHERE clause with comparison operators
  • ✅ Basic JOIN operations
  • ✅ DROP TABLE support

Example Commands

CREATE TABLE products (id INTEGER PRIMARY KEY, name TEXT NOT NULL, price REAL)
INSERT INTO products (id, name, price) VALUES (1, 'Laptop', 999.99)
SELECT * FROM products
SELECT name, price FROM products WHERE price > 500
UPDATE products SET price = 899.99 WHERE id = 1
DELETE FROM products WHERE id = 1
SELECT * FROM users JOIN tasks ON users.id = tasks.user_id

Architecture

SimpleDB is built from scratch in JavaScript with no external dependencies. It features a columnar storage model with automatic indexing, constraint validation, and a simple SQL parser. The implementation demonstrates core RDBMS concepts including B-tree-style indexing (using Map data structures), transaction-like operations, and relational algebra.
